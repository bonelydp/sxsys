# Bioinformatics software packages

Place these Linux x86_64 packages in this directory before building the backend:

- `ncbi-blast-2.15.0+-x64-linux.tar.gz`
- `mafft-7.526-gcc_fc6.x86_64.rpm`
- `iqtree-3.1.2-Linux-intel.tar.gz`

The installers are intentionally excluded from Git because the BLAST archive
exceeds GitHub's normal 100 MB per-file limit.

# Shouyi Frontend

隐孢子虫数据管理与生物信息分析平台前端，基于 Vue 3。

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Lints and fixes files
```
npm run lint
```
